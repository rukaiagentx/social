# Social Media Content Store

Generated assets for social media posting. Each folder is date-stamped.

## URL Format

All images are publicly accessible via:
```
https://raw.githubusercontent.com/rukaiagentx/social/main/content/<YYYY-MM-DD>/<filename>
```

## Structure

```
content/
  2026-05-31/
    poster-instagram-square.png
    poster-instagram-portrait.png
    metadata.yaml
  2026-06-01/
    ...
```

## Metadata

Each date folder includes a `metadata.yaml` with:
- Image filenames and public URLs
- Caption text
- Channel targets
- Creation timestamp
- Whether the content has been posted
